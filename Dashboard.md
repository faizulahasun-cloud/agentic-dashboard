# Dashboard

⌂ **[Open the Agentic dashboard](obsidian://agentic-dashboard?action=open-dashboard)**

---

This note is a template shipped with the **Agentic dashboard** plugin. Copy it anywhere into your vault (the filename becomes the link target), then set **Dashboard note** in the plugin settings to this note's name — every daily note the plugin creates will link back to it.

## What the dashboard gives you

- **Tasks today** — open tasks from today's daily note plus everything due or overdue across the vault; click to complete, form to create (with priority, repeat rules and future dates)
- **Calendar** — this month with your daily notes marked
- **Quick capture** — one-line thoughts to the Inbox, rich forms for meetings, reflections, to-watch and books
- **At a glance** — clickable stats: notes, open/done tasks, inbox, today's meetings, last 7 days
- **Agent-ready** — Obsidian CLI commands and `obsidian://` URI actions so agents and scripts can drive your vault

> The plugin renders the dashboard as its own view — this note is simply a home for it in your graph, linked from every daily note.
